# Decision log

Short records of decisions that would otherwise get re-litigated. One file per
decision, numbered, append-only (supersede rather than delete). This matters here
because a lot was locked during planning — this is the "why" so future-you doesn't
re-open settled ground.

Format per file:
- **Context** — what forced the decision.
- **Decision** — what was chosen.
- **Consequences** — what it costs / enables.
- **Status** — Accepted / Superseded by NNNN.
